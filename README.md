# Java Fundamentals

Small Java examples covering input, arithmetic, control flow, types, and packages.

Compile and run a default-package example from this directory, for example:

```text
javac Add_Numbers.java
java Add_Numbers
```

The user-defined package example is in `PackagesUserDefined`. From that directory:

```text
javac Main.java com/myapp/utilities/UtilityClass.java
java Main
```
